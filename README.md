# E-Commerce Sales Analysis using Python

## Project Overview
This project focuses on analyzing e-commerce sales data to identify sales trends, product performance, customer behavior, and business insights.

## Dataset Information
- Dataset: Sample Superstore
- Total Records: 9,994
- Total Columns: 21

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Category-wise Sales and Profit
- Region-wise Sales and Profit
- Monthly Sales Trends
- Top 10 Products Analysis
- Customer Segment Analysis
- City-wise Sales Analysis
- Discount vs Profit Analysis
- Year-wise Sales and Profit

## Key Insights
- Technology generated the highest category sales.
- West region recorded the highest sales.
- Consumer segment generated the highest profit.
- New York City had the highest sales.
- Tables, Bookcases, and Supplies generated losses.
- 2017 recorded the highest annual sales.

## Conclusion
The analysis helps identify profitable products,
high-performing regions, and sales trends to support
better business decisions.
